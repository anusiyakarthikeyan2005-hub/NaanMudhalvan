# SwiftShip Tracker

A Salesforce CRM parcel-management portal concept for booking parcels, tracking delivery status, and managing shipments. The project brief describes a conversational AI agent that helps customers book parcels, get live tracking updates, and manage deliveries in one place, while staff update parcel details, delivery timelines, and statuses.

## Objective

Build a comprehensive parcel-management experience on Salesforce CRM with an intuitive customer interface and transparent delivery communication.

## Intended outcomes

- Practice Salesforce custom-object configuration.
- Automate parcel-management processes with Salesforce Flows.
- Understand the end-to-end CRM project lifecycle, from requirements to deployment.
- Explore conversational AI/Agentforce interactions for customer service.

## Core capabilities described in the brief

- Parcel booking and parcel-detail management.
- Delivery-status and tracking updates.
- Delivery timeline management.
- Customer communication about parcel status.
- Conversational AI assistance for common parcel-service interactions.
- Salesforce Flow automation and Agentforce troubleshooting/maintenance.

## Salesforce implementation outline

1. Create/configure the parcel data model (the brief references a custom Parcel object).
2. Configure the required fields and record pages based on the project requirements.
3. Build Flows for the parcel-management steps and status updates.
4. Configure the customer-facing experience and agent/staff access as required.
5. Configure and test conversational AI/Agentforce interactions, if included in your Salesforce org.
6. Test booking, tracking, status updates, and error/exception scenarios.
7. Document deployment and ongoing monitoring.

> This repository is a starter documentation package prepared from the readable parts of the uploaded screen recording. It is not a complete Salesforce metadata export or deployable application. Exact field names, Flow definitions, Apex/LWC source, and some setup values were not legible enough in the video to reproduce reliably.
